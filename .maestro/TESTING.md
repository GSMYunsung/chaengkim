# 화면 테스트 (Maestro)

실행·규칙은 전역 `maestro-test` 스킬에 있다. 이 파일은 **챙김만의 지식**을 담는다.

- 설정: `.maestro/config.sh` · 시나리오: `.maestro/flows/NN-*.yaml` · 공통 흐름: `.maestro/subflows/`
- 실행: `~/.claude/skills/maestro-test/scripts/run.sh` (프로젝트 루트에서, Metro 8082는 expo-dev-run 스킬로)
- 첫 화면 문구(공통 흐름 TARGET): `"(?s).*잊기 쉬운 순간에.*"`
- 새로 설치하면 소지품이 0개다. 01이 지갑·열쇠·에어팟을 담고, 뒤 시나리오는 이 3개를 전제로 한다(05 지갑 빼기, 06·08 열쇠).

## 화면 ↔ 시나리오

기능·화면·문구를 바꾸면 아래 표에서 해당 시나리오를 찾아 같은 작업 안에서 고친다. 새 화면이면 행과 시나리오를 추가한다.

| 화면(소스) | 시나리오 |
|---|---|
| `app/onboarding.tsx` (3단계 "+ 추가", 0개면 알림 → `app/item-edit.tsx`) | 00 준비, 01 온보딩, 13 위치 거부 + `subflows/onboarding-add-item.yaml` |

| `app/(tabs)/index.tsx` 홈 (외출 전/중, 지금 출발, 테스트 랩 버튼, 위치 꺼짐 안내) | 02, 05, 07, 08, 09, 10, 13 |

## 챙김에서 겪은 실패와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 빨간 LogBox 화면 | 시뮬레이터의 일시적 위치 오류가 `console.error`로 찍힘 | 앱에서 무시하도록 처리됨. 다시 생기면 앱 쪽 원인을 고친다 |
| `지금 출발` 버튼을 못 찾음 | 아이콘 문자가 라벨 뒤에 붙음(`지금 출발, `) | `"지금 출발.*"` |
| 출발 시각 입력이 이상함 | 커서가 가운데 | `point: "95%,50%"` |
| 테스트 랩에서 돌아가기 | iOS에는 `back` 없음 | `tapOn: { id: "BackButton" }` |
| 01 온보딩 "계속"을 눌렀는데 그대로, 위치 권한 버튼 WARNED → 02부터 연쇄 실패 | 00이 알림 창을 닫은 직후의 탭이 무시됨(간헐적) | 01·13은 `tap-until.yaml`로 "돌아올 곳을"이 보일 때까지 권한 버튼(PROMPT)과 "계속"을 누른다 |
| 탭마다 6~8초, 가끔 탭 전환이 안 됨(03 "추가" 못 찾음 등) | 마스코트·가방 반복 애니메이션으로 화면이 멈추지 않음 + 저장 후 닫히는 중의 탭 무시 | 앱은 동작 줄이기를 이미 지원 → run.sh가 시뮬레이터 동작 줄이기를 켬(탭 1초). 하단 탭은 `subflows/tap-tab.yaml` |
| 04 저장 직후 "장우산"을 눌렀는데 편집 화면이 안 열림 | 편집 화면이 닫히는 중의 탭 무시 | `tap-until.yaml`로 "이 소지품 삭제"가 보일 때까지 다시 누름 |
| 13 "자리 뜰 때 알림이 꺼져 있어요" 못 찾음 | `Row` 라벨이 `", 제목, 설명, "` 형식 | `"(?s).*자리 뜰 때 알림이 꺼져 있어요.*"` |
| 05 "챙기고 외출 시작"을 눌렀는데 그대로 | 체크 직후 버튼 문구가 다시 그려지는 중의 탭 무시 | `tap-until.yaml`로 "외출 중"까지 |
| 13 위치 거부에서 권한 창이 안 뜸 | `launchApp`이 위치를 자동 허용 | `permissions: { location: unset }` |

## 시뮬레이터로 확인할 수 없는 것

실제 백그라운드 위치 감지와 알림 수신, 프로덕션 빌드에서 테스트 도구가 숨는지, 지도 핀 내용. 폰에서 확인한다.
