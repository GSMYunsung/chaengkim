# 되돌리기 (revert-change)

목표는 "방금 구현한 것만" 정확히 걷어내고, 그 사이 사용자가 직접 고친 내용은 지키는 것이다.
기억이나 대화 기록으로 이전 코드를 다시 타이핑하지 않는다. 서식, 주석, 사용자의 수정이 어긋나기 쉽기 때문이다. 항상 스냅샷에서 복원한다.
사용자 응답과 진행 보고는 한국어로 한다.

스크립트: `.claude/skills/revert-change/scripts/snap.sh` (아래에서는 `snap.sh`)

| 명령 | 하는 일 |
|---|---|
| `snap.sh save "<작업 요약>"` | 지금 작업 트리 전체(추적 + 미추적, gitignore 제외)를 스냅샷으로 저장 |
| `snap.sh list` | 스냅샷 목록 (최신순) |
| `snap.sh diff [id]` | 복원하면 바뀔 파일. `A`는 스냅샷 이후 새로 생긴 파일(삭제됨), `M`/`D`는 원래 내용으로 복원 |
| `snap.sh restore [id] [-- 경로...]` | 복원. id를 생략하면 최신 작업 스냅샷. 경로를 주면 그 파일만 |

스냅샷은 `refs/snapshots/` 아래의 로컬 커밋 객체다. HEAD, 브랜치, 인덱스(staged)를 건드리지 않고 push되지 않는다.
restore는 실행 직전 상태를 `pre-restore-…`로 자동 저장하므로, 되돌리기 자체도 되돌릴 수 있다.

## 1. 구현 직전: 저장

코드, 설정(app.json, package.json), 에셋을 바꾸는 **첫 수정 직전**에 한 번 실행한다.

```bash
.claude/skills/revert-change/scripts/snap.sh save "홈 가방 히어로와 담기 애니메이션"
```

- 사용자 요청 하나(확정된 작업 하나)마다 하나를 남긴다. 같은 작업 안에서 파일을 고칠 때마다 남기지 않는다.
- 요약은 사용자가 목록에서 알아볼 수 있게 무엇을 바꾸는지로 쓴다.
- 의존성 설치(`expo install`)도 이 작업에 포함되면 설치 전에 저장한다. package.json과 lock 파일이 함께 복원된다.

## 2. 되돌리기 요청: 대상 확인

1. `snap.sh list`로 어느 스냅샷이 "이전"인지 정한다. 보통은 가장 최근 작업 스냅샷이다. 사용자가 "두 번 전", "가방 작업 전" 처럼 말하면 요약으로 찾는다.
2. `snap.sh diff <id>`로 바뀔 파일을 본다.
3. 목록을 **그 작업에서 내가 바꾼 파일**과 대조한다.
   - 목록에 내가 건드리지 않은 파일이 있으면, 작업 후 사용자가 직접 고친 것이다. 그 파일은 빼고 `restore <id> -- <내가 바꾼 경로...>`로 복원하고, 빼 둔 파일을 보고한다.
   - 내가 바꾼 파일을 사용자도 이후에 고쳤다면(`git diff`로 내 변경이 아닌 줄이 보이면) 복원하기 전에 물어본다. 복원하면 사용자의 수정도 사라진다.
4. 스냅샷이 없으면(저장을 빠뜨린 작업) git으로 대신할 수 있는지 본다. 작업 전 상태가 마지막 커밋과 같으면 `git diff -w HEAD -- <파일>`로 내 변경만 있는지 확인한 뒤 `git restore -- <파일>`로 되돌리고, 새로 만든 파일은 지운다. 둘 다 아니면 사용자에게 알리고 어떻게 할지 묻는다.

## 3. 복원하고 확인한다

```bash
.claude/skills/revert-change/scripts/snap.sh restore <id> [-- 경로...]
npx tsc --noEmit
```

- package.json이나 lock 파일이 복원됐으면 `npm install --legacy-peer-deps`로 node_modules를 맞춘다.
- app.json의 `plugins`, 권한, 폰트처럼 네이티브 설정이 복원됐으면 `npx expo prebuild --platform ios` 후 재빌드가 필요하다고 알린다 (expo-dev-run 스킬 3-B).
- JS만 바뀌었으면 폰에서 Reload만 하면 된다.

## 4. 보고

- 어느 시점으로 돌아갔는지 (스냅샷 요약)
- 복원한 파일과 삭제한 파일
- 일부러 남긴 파일과 그 이유 (사용자 수정 등)
- 되돌리기를 취소하는 방법: `snap.sh restore pre-restore-…`

## 하지 말 것

- 기억이나 대화에 남은 코드로 파일을 다시 써서 "되돌렸다"고 하기
- `git reset --hard`, `git checkout .`, `git stash` 같이 작업 트리 전체를 덮는 명령 쓰기 (사용자의 다른 변경까지 사라진다)
- 스냅샷 ref 지우기 (사용자가 요청할 때만)
- 스냅샷 저장을 빠뜨리고 구현 시작하기
